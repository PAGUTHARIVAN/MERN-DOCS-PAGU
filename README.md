# My React App

A multi-page React app I built while learning React and React Router.

## Features

- Todo app: add, toggle, delete, filter (all / done / pending)
- Job application form with validation
- Users list with dynamic routes (`/users/:id`)
- Shared layout with navigation (NavLink)
- 404 page

## Tech Stack

React, Vite, React Router

## Run Locally

    git clone <your-repo-url>
    cd my-react-app
    npm install
    npm run dev

## What I Learned

Controlled forms and validation, useRef, useEffect,
lists and conditional rendering, React Router (Layout, Outlet,
useParams, useNavigate).
